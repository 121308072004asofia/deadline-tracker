# Трекер дедлайнов

Данная программа собирает мои дедлайны по всем предметам в одном месте и каждый запуск показывает, какой проект является наиболее приоритетным -- сроки вот-вот настанут

## Какую рутину автоматизирует

Раньше я каждый день открывала таблицу дедлайнов курса и чаты групп, сверяла даты и вспоминала, что уже сдала, обычно это занимало минимум около 15 минут в день, но теперь можно раз в несколько дней выгружать таблицу в CSV и загружать в эту программу, чтобы она сама сортировала вск задания и потом помнила, что уже сдано, а что только предстоит

## Как запустить

Нужен Python 3.10 или новее. Сторонние библиотеки для запуска здесь не понадобятся

```
git clone <ссылка на репозиторий>
cd deadline-tracker
python main.py
```

На macOS вместо `python` может понадобиться `python3`

Чтобы попробовать на примере, в меню выберите `2` и введите путь `example/deadlines_example.csv`.

## Формат входного файла

CSV с колонками `Предмет`, `Задание`, `Дата` и необязательной `Тип`. Разделитель `;` или `,`

## Что программа делает

1. Показывает несданные задания по группам: просрочено, сегодня, скоро (до 3 дней), потом
2. Загружает дедлайны из CSV: новые добавляет, перенесенные обновляет, повторы пропускает
3. Отмечает задание сданным
4. Добавляет дедлайн вручную
5. Делает отчет и сохраняет его в `report.txt`

Состояние хранится в `data/deadlines.csv`, поэтому между запусками ничего не теряется. Папка `data/` не попадает в репозиторий, потому что там мои личные данные.

## Мои правила

- Сортировка: сначала ближайшая дата. Если даты одинаковые, выше то, что важнее по типу: экзамен и проект (3), контрольная и ДЗ (2), тест и другое (1)
- «Скоро» значит не больше 3 дней (`URGENT_DAYS` в `priority.py`)
- Одно и то же задание узнается по паре (предмет, название) без учета регистра. Если у него новая дата, значит дедлайн перенесли

## Грязные данные и краевые случаи

| Что встретилось | Что делает программа 
| Дата с временем `24.10.2026 23:59` | время отбрасывается |
| Разные форматы дат: `24.10.2026`, `24.10.26`, `2026-10-24`, `24/10/2026` | пробует форматы по очереди |
| Дата без года `28.10` | берет текущий год |
| Дата словами `до пятницы` | строка пропускается с понятной причиной |
| Несуществующая дата `31.02.2026`, `29.02` в невисокосный год | строка пропускается с причиной |
| Пустой предмет или название | строка пропускается с причиной |
| Полностью пустые строки | молча пропускаются |
| Лишние пробелы и разный регистр: `  ДЗ `, ` Линал ` | обрезаются, тип приводится к нижнему регистру |
| Неизвестный тип задания, например `консультация` | тип становится `другое` |
| Повторная загрузка того же файла | дубликаты не добавляются, отметка «сдано» сохраняется |
| Дедлайн перенесли | дата обновляется, программа пишет, сколько перенесено |
| Excel сохранил CSV с `;` и в кодировке Windows-1251 | разделитель и кодировка определяются сами |
| Нет нужных колонок или в файле только заголовок | понятное сообщение, ничего не ломается |
| Путь к файлу в кавычках (так копирует Windows) | кавычки убираются |
| Файла нет или вместо файла папка | сообщение об ошибке, программа продолжает работу |
| Испорченная строка в `data/deadlines.csv` | программа предупреждает, какие строки не прочитались |
| Буквы вместо номера в меню, номер вне списка, пустой ввод | переспрашивает |
| Ctrl+C во время работы | аккуратно завершается без traceback |

## Устройство

| Файл | Что внутри |
| --- | --- |
| `main.py` | меню и общение с пользователем |
| `models.py` | класс `Deadline`: один дедлайн и сколько до него дней |
| `storage.py` | класс `DeadlineStore`: загрузка, сохранение и слияние дедлайнов |
| `importer.py` | чтение чужого CSV и чистка данных |
| `priority.py` | правила сортировки, группы и отчет |
